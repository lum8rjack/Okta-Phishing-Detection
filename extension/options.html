Okta Phishing Detection

What this extension does

This extension helps you spot fake Okta login pages. It checks each page that looks like Okta and compares it to the site’s domain. If the page looks like Okta but the URL is not a subdomain of okta.com, it’s likely a phishing site. In that case, a red warning banner appears at the top of the page.

On real Okta pages (e.g. your-company.okta.com), no banner is shown. There are cases where companies use a custom domain for their Okta login page, in which case you can add the domain to the allow list to prevent the warning from being shown.

Settings

The message shown in the red warning bar at the top of the page.

Enter one domain per line. If the current page’s domain matches a domain in this list, or is a subdomain of a listed domain (for example, "okta.example.com" is covered by "example.com"), the extension will not show a warning. This is useful for trusted custom Okta pages that may otherwise be flagged by mistake.
